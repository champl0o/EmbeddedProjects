# Police Blink

Імітація поліцейської мигалки на ESP32-S3: 4 зовнішні світлодіоди (2 червоних + 2 синіх) під PWM, вбудований RGB-світлодіод та анімація поліцейської машини на OLED-дисплеї.

## Що робить

- Грає 4 патерни мигалки на зовнішніх LED, перемикаючи їх по колу кожні 6 с:
  - **WIG-WAG** — ліва пара / права пара чергуються
  - **RUNNING** — біжуча хвиля по всіх каналах
  - **QUAD-FLASH** — 4 швидких спалахи кожним боком
  - **FADE** — плавне перетікання червоний ↔ синій
- Вбудований RGB блимає червоним і синім у такт.
- На OLED 128×64 їде анімована поліцейська машина з підписом активного патерну.

## Залізо

- Плата: **ESP32-S3-DevKitC-1**
- Дисплей: **SSD1306 128×64**, I²C
- 4 зовнішні світлодіоди з токообмежувальними резисторами (≈220 Ом)

### Розпіновка

| Сигнал       | GPIO   |
|--------------|--------|
| SDA (OLED)   | 20     |
| SCL (OLED)   | 21     |
| Червоні LED  | 18, 13 |
| Сині LED     | 17, 16 |
| Вбудований RGB | `LED_BUILTIN` |

## Збірка

Проєкт PlatformIO, фреймворк Arduino.

```bash
pio run            # компіляція
pio run -t upload  # прошивка
pio device monitor # серійний монітор (115200)
```

## Структура

```
include/
  config.h            — піни, кількість каналів, PWM, таймінги
  patterns.h          — структура Pattern + декларації
  led_driver.h        — ledDriverBegin(), applyFrame()
  police_display.h    — displayBegin(), drawPoliceCar()
src/
  patterns.cpp        — 4 таблиці кадрів + масив patterns[]
  led_driver.cpp      — гамма-таблиця, PWM, applyFrame
  police_display.cpp  — OLED, геометрія, малювання машини
  main.cpp            — стан, кооперативний планувальник, setup/loop
platformio.ini        — конфіг плати та бібліотек
```
